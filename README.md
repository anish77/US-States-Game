# 🇺🇸 U.S. States Game

An interactive **U.S. States guessing game built with Python using the `turtle` and `pandas` libraries.

The goal of the game is to guess all 50 U.S. states. When a correct state is entered, its name appears in the correct position on the map.

## 🎮 How to Play

1. Run the game.
2. Enter the name of a U.S. state.
3. If the answer is correct, the state name will appear on the map.
4. Continue until you guess all 50 states.
5. Type `Exit` to stop the game.

When you exit the game, a CSV file containing the states you didn't guess will be created so you can study them later.
